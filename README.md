# Study Focus Guard (勉強脱線防止拡張機能)

勉強中にYouTubeやSNSなどの誘惑に負けないためのChrome拡張機能です。
閲覧中のページが「勉強に関連しているか」をAIがリアルタイムで判定し、無関係なコンテンツには警告を表示します。YouTube ShortsやInstagramは強制的にブロックされます。

**🌐 日本語・English 対応**

📄 [事業計画書はこちら](https://anomori.github.io/study-focus-extension/)

## 🚀 インストール方法

### Chrome ウェブストアからインストール（推奨）

[Chrome ウェブストア](https://chromewebstore.google.com/) で「**Study Focus Guard**」を検索し、「Chromeに追加」をクリックしてください。

### 開発者モードでインストール

1. このリポジトリをZIPでダウンロードし、解凍します（または `git clone`）。
2. Chromeで `chrome://extensions/` を開きます。
3. 右上の **「デベロッパー モード」** をONにします。
4. **「パッケージ化されていない拡張機能を読み込む」** をクリックし、解凍したフォルダ（`manifest.json` があるフォルダ）を選択します。

## 📖 使い方

1. **初回セットアップ**:
   - インストール後、初回起動ダイアログが表示されます。
   - データ記録の設定（我慢回数・閲覧時間・SNS時間のみ）を選択します。
   - 記録しない場合はそのままスキップできます。

2. **勉強内容を登録する**:
   - 拡張機能のアイコンをクリックし、ポップアップを開きます。
   - 勉強するトピックを入力して「追加」します（例: `English`, `React`, `線形代数`）。
   - 各トピックはON/OFFトグルで有効/無効を切り替えられます。
   - 登録したトピックは**関連語に自動展開**されます（例: 「プログラム」→「プログラミング」「コーディング」等）。

3. **勉強を始める**:
   - YouTubeやWebページを閲覧します。
   - 勉強と無関係なページを開くと、画面が警告で覆われます。
   - 本当に勉強に必要な場合は「関係ある（閉じる）」を押して続行できます（2分後に再チェック）。

4. **一時的に無効化する**:
   - ポップアップの **「🔍 判定機能」** トグルでAI判定のON/OFFを切り替えられます。
   - **「🛡️ ブロック機能」** トグルでサイトブロックのON/OFFを切り替えられます。

5. **詳細設定を使う**:
   - ポップアップの「詳細設定」ボタンをクリック。
   - **サイト設定**: 許可サイト・禁止サイト・禁止パターンを自由に追加/削除。
   - **詳細設定**: 言語設定、記録設定、タイムゾーン設定。
   - **統計**: 日別/月別のグラフで閲覧時間を確認。棒をクリックで詳細表示。
   - **データ管理**: エクスポート/インポート、期間指定でのデータ削除。

## ✨ 機能

### 🤖 AIによる関連性判定
- 登録した勉強内容（例: "Programming", "Math"）と閲覧中のページの意味的な関連性を判定
- **Transformers.js (MiniLM-L12)** を使用し、ブラウザ内で完結するローカル推論（プライバシー重視）
- **トピック自動展開**: 登録した勉強内容から関連キーワードを自動生成（日英対応）
- 学習系コンテンツ（YouTubeの教育カテゴリなど）はスコア優遇
- **30秒ごとの定期判定**で常時監視
- ページタイトル・H1・meta description・YouTubeメタデータ（ジャンル、詳細説明）を解析

### 🚫 完全ブロック（カスタマイズ可能）
- **YouTube Shorts** (`youtube.com/shorts/`) — デフォルトでブロック
- **Instagram** (`instagram.com`) — デフォルトでブロック
- **カスタム禁止サイト・禁止パターン**: 詳細設定から自由に追加可能
- **許可サイト**: 禁止より優先、スコア測定・警告をスキップ
- **デフォルト許可サイト**: 政府・教育機関サイト（`go.jp`, `ac.jp`, `ed.jp`, `lg.jp`）

### ⚠️ 脱線警告
- **警告オーバーレイ**: 類似度が低い場合、"🥺" キャラクターと共に「勉強に関係ありますか？」と警告
- **再判定機能**: 警告を閉じても**2分後に再チェック**し、まだ脱線していれば再度警告
- **SNS・動画サイト補正**: Twitter/X、Facebook、TikTok、Netflix、Prime Video、Hulu、ニコニコ動画等にはペナルティを適用
- **Twitter/X追加補正**: ホームタイムラインはさらに厳しく判定

### 📊 統計機能（任意）
- **我慢回数**: 警告を閉じずにページを離れた回数を記録
- **閲覧時間**: どのサイトをどれくらい見たかを記録
- **グラフ表示**: 日別・月別の棒グラフ（クリックで詳細な時間・回数を確認可能）
- **判定ON/OFF別フィルター**: ONの時/OFFの時/合計で切り替え可能
- **タイムゾーン対応**: 自動検出・地域選択・手動UTC入力に対応
- **自動パージ**: 90日を超えた古い統計データは自動的に削除
- **プライバシー重視**: すべてローカル保存、データ削除も可能

### 🎛️ コントロール機能
- **判定機能ON/OFF**: AIによる関連性チェックをワンクリックで切り替え
- **ブロック機能ON/OFF**: サイトブロック機能を独立して切り替え
- **トピックON/OFF**: 各勉強内容を個別に有効/無効切替可能
- **スコア表示**: デバッグモードON時、ポップアップで現在のページの判定スコアをリアルタイム表示
- **詳細設定**: サイト設定・記録設定・統計閲覧・データ管理

### 📤 データエクスポート/インポート
- **JSONエクスポート**: 設定・勉強項目・統計データのバックアップ（内容を個別に選択可能）
- **CSVエクスポート**: 閲覧時間CSV・我慢回数CSVを個別に出力（Excel対応のBOM付き）
- **期間指定エクスポート**: 開始日・終了日を指定して必要なデータだけ出力
- **JSONインポート**: マージまたは置き換えモードを選択してリストア

### 🌐 多言語対応
- **日本語 / English** の2言語に対応
- ポップアップ・設定画面・警告オーバーレイ・初回ダイアログすべてが翻訳対応
- 詳細設定の言語設定から切り替え可能

## 🛠 技術的な仕組み

| コンポーネント | 役割 |
|--------------|------|
| `content.js` | ページ情報の取得、DOM操作（オーバーレイ表示）、定期判定、我慢イベント検出 |
| `background.js` | オフスクリーンAPI制御、タブごとのスコア管理、閲覧セッション追跡、自動パージ |
| `offscreen.js` | サンドボックスとの通信ブリッジ |
| `sandbox.js` | AIモデルの実行環境（Wasm制約の回避） |
| `popup.html/js` | ユーザーインターフェース（ポップアップ） |
| `settings.html/js` | 詳細設定・統計画面 |
| `statistics-storage.js` | 統計データの保存・取得・削除・エクスポート/インポート |
| `i18n.js` | 国際化（日本語/英語の翻訳処理） |
| `first-run-dialog.html/js` | 初回起動時のセットアップダイアログ |

**Embedding Model**: `Xenova/paraphrase-multilingual-MiniLM-L12-v2`（約20MB、50以上の言語に対応）
**Chart Library**: Chart.js（グラフ表示用）
**Platform**: Chrome拡張機能（Manifest V3）
